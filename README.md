# criminal-risk-assessment-assignment
# Criminal Risk Assessment Request – ODK XLSForm

## Assignment Overview

This project contains an ODK XLSForm developed based on the provided
Criminal Risk Assessment Request PDF.

The purpose of this assignment is to convert the provided form into a
structured digital form using the ODK XLSForm format.

## Project Files

### 1. XLSForm

`criminal_risk_assessment_request (4).xlsx`

This is the main XLSForm developed for the assignment.

The workbook contains:

- Survey sheet
- Choices sheet
- Settings sheet

### 2. Reference PDF

`Criminal Risk Assessment Request.pdf`

This is the reference PDF used to develop the ODK XLSForm.

### 3. Assignment Video

The assignment demonstration video is included in this repository.

The video demonstrates the XLSForm structure, validation, and the
generated form preview in the browser.

## XLSForm Structure

### Survey Sheet

The Survey sheet contains the questions and structure of the form,
including the question types, field names, labels, required fields,
constraints, and other form configurations.

### Choices Sheet

The Choices sheet contains the predefined options used by the form,
including the choices used for select-one and select-multiple questions.

### Settings Sheet

The Settings sheet contains the form metadata such as the form title,
form ID, version, and language.

## ODK XLSForm Validation

The completed XLSForm was uploaded to the ODK XLSForm Online validator
to check whether the form could be successfully converted into an ODK
XForm.

The form was successfully validated and converted.

## Form Preview

After successful validation, the generated form was opened using the
"Preview in Browser" option.

The browser preview displays the Criminal Risk Assessment Request form.
The preview was used to verify the form structure, fields, choices,
required fields, and overall appearance.
